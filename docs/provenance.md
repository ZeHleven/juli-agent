# 设计来源与当前迁移范围

本工程来自“据理——结合你的资料，分析眼前的问题”的通用框架设计。设计参考已有新版 Pure Agent 中的动态行动、任务状态、版本化资料、证据回读、工具权限和场景指导边界。

参考项目：`ZeHleven/AI_Quotation_System` 的本地新版独立服务适配。第一步清点包含 132 个候选文件；M00 开始时已复核哈希与清点基线一致。由于当时候选目录尚未被原 Git 跟踪，原 HEAD 不能单独复现其内容。

本轮建立新的通用合同和加载/注册实现，未整目录复制原业务源码，未迁入原执行器、旧退役 Agent、原数据库迁移、真实企业资料或运行凭据。保留的是经过明确泛化的接口概念与规则，后续模块迁入需逐项记录来源。

M02 的 SQLite 适配器与 M03 的通用文件处理、词项索引、证据读取为该独立工程新增实现，未复制原业务解析链或连接旧资料库。DOCX 使用 Python 标准库读取正文 XML；PDF 通过声明的可选 pypdf 依赖解析。测试资料由代码生成，不含真实企业或个人文件。

M04 新增供应商无关模型合同、上下文与网关、单对象分步会话，以及使用 HTTPX 的 Chat Completions 协议适配器。协议依据和支持范围记录于 [模型指南](models.md)。验证只用脚本响应、模拟 HTTP 与合成库，没有引入原项目模型密钥、运行器或供应商 SDK。

本工程可独立打包；安装依赖是正常 Python 第三方库，不要求原报价应用或循练目录存在。场景示例全部为方法描述与合成资料，不包含真实个人背景。

M05 在独立工程中新增 SQLite 动作账本、持久运行器和离线生命周期演示；没有复制原项目生产数据库、凭据或运行记录。

M06 新增同源静态工作台、带动作计数条件的执行端点、确定性离线界面夹具。样式和交互直接在独立包编写，没有复制原业务前端、第三方素材或用户数据。

M07 新增独立 LangGraph 对照实验，只引用安装依赖，不复制框架源码；实验不进入正式 wheel。M08 新增三个场景的合成验收、设备选择扩展包与服务端预算配置，不含真实背景资料。

M09 新增安装、部署、贡献和发布说明、MIT 文本、经维护者批准的安全策略，以及本地源码发布检查工具。依赖清单从独立虚拟环境的安装元数据生成，不包含本机绝对路径、凭据或运行数据库。本阶段没有对外发布。

E01/E02 新增自主编写的合成评测资料、人工标准、来源定位和独立冒烟入口。DeepSeek 评测适配层参考官方 API 的非思考模式和费用文档，通过既有 HTTPX 与据理公共运行接口实现，未复制第三方 SDK 源码。协议来源、选定版本和范围记录于 [E02 计划](evaluation/round-02-smoke.md) 与 [运行说明](evaluation/smoke-running.md)。密钥及原始运行数据只放在忽略的 `.local` 中，不属于发布源码。

E03 根据 E02 实际合成响应扩展模型批次合同、HTTP 消息保真和持久串行队列，均为本工程新增修改。原失败返回与修改前源码在本地保留，没有复制供应商 SDK、原业务数据库或真实背景资料。预算继承入口保留上一轮未知调用预留；开发笔记与未发布公众号素材在据理目录单独记录。

E04基于E03三题的真实失败证据，自主编写模型侧原生结果解析、统一分析/追问指令及新增轮次预算继承入口。没有修改冻结题目或场景schema，没有复制第三方提示模板、引入供应商特有结构化API或接入真实个人/企业资料。旧失败原文和费用预留继续保留。

E05基于E04缺失信息题跳过回读与追问的原始轨迹，自主编写可选草稿审查流程、持久阶段与框架回读调度、严格审查结构及连续费用账本。使用既有工具网关与证据验证，不迁入旧业务数据、第三方提示模板或SDK，不改变冻结资料与场景答案。框架安排的工具消息显式标注来源，开发协作Agent不是据理运行时的多Agent架构。

E06基于E05三份失败原响应，自主编写模型可见Schema补充、共享输出与工具依赖提示、v2配置指纹、独立预算继承入口及合成测试。没有复制供应商SDK或第三方提示模板，不改变冻结资料、场景与金标。真实新试次只发送既有合成资料；原失败、预算回归、所有压缩尝试与未测范围保留，本地草稿不代表发布。

E07基于E06岗位题关键问题仅留在最终报告的原始响应，自主编写显式关键问题声明、候选校验及pending提交、v3指纹和合成回归。没有引入新第三方依赖、模型模板、场景专用判断或真实业务资料；全部验证离线，未读取密钥。旧回复按原字节回放，新合成回复明确标记，不冒充模型自行改善；公开图为代码绘制的机制示意。

- 24 项独立对照测试全部通过：同一任务快照、四次完全相同的假模型请求、相同工具、结果、预算计数和事件种类；追问到完成共 6 个动作。时长不作为相等条件或性能结论。

- 两种调度均经过原有账本和网关，保留取消/撤权/撤下资料后的迟到结果拒绝、预算、防重、未知动作停止、引用回读和工具授权检查。这些是复用据理机制的结果，不是 LangGraph 自带的业务保证。
- 独立子进程验证 LangGraph SQLite 中断与回答恢复；观察到中断节点重入，符合官方语义。
- 在据理动作已提交而图节点尚未返回时强制结束子进程：即使图启用同步检查点，恢复仍会遇到旧动作计数；据理阻止重复执行，但需要读取权威状态并明确重新调度。没有将它包装成自动恢复成功。
- 对照使用新合成资料，父子测试进程阻止网络连接并关闭追踪，没有真实模型调用。实验关键依赖独立列出，未修改正式依赖；测试环境出现一项已有 requests 依赖版本警告，不影响断言通过。
- 正式 wheel 构建并核验：不包含实验文件，也没有 LangGraph / LangChain 依赖。包版本维持 `0.1.0.dev5`，因为运行时能力没有变化。

选定继续使用现有 `DurableRunner`，保留一套业务状态权威；暂不接入 LangChain 或多 Agent。详见 [决策依据与适用限制](decisions/0001-runtime.md)、[复现实验](../experiments/m07_langgraph/README.md) 和 [机器可读结果](../experiments/m07_langgraph/results.json)。

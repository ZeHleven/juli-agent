# 数据分析岗位说明

本材料为合成岗位资料，不对应任何真实招聘主体。所有时间判断以 2026-10-02 为准。

## 工作内容

岗位负责梳理服务运营数据，将业务问题整理为指标口径，使用 SQL 提取数据、使用 Python 完成重复分析的自动化，并向业务同事解释结果。

## 任职条件

录用流程进入业务面试前，必须满足至少三年全职数据分析工作经验；实习、课程作业和个人练习不计入这个年限。

需要能够独立编写 SQL 多表查询，并用 Python 维护可重复运行的数据清洗脚本。

需要有一次与非技术同事共同确认指标口径、根据反馈修改分析结果的经历。

每周须到现场工作三天，其余工作日可以远程；这是当前岗位的固定安排，不能以全远程替代。

熟悉图表设计属于加分项，不是进入面试的必备条件。岗位没有证书、学历层次或特定行业经历的附加门槛。

是否发放录用通知，还要结合实际面试、作品核验和双方沟通决定；岗位说明不承诺对任何申请人录用。
